# سحاب — مواصفات المشاهد ثلاثية الأبعاد

> هذا الملف هو "روح" المشروع. أي قرار بصري يخص الخلفية يُكتب هنا.

---

## 1. الفلسفة

- **مشهد واحد حيّ، وليس مشاهد متعددة.** عندنا عالم 3D واحد فيه كل الطبقات (سماء، شمس، قمر، نجوم، غيوم، مطر، ثلج، ضباب، برق). كل طبقة لها "شدة" من 0 إلى 1. الطقس = مجموعة أرقام.
- **الانتقال = interpolation للأرقام.** من مطر إلى شمس: شدة المطر 1→0، كثافة الغيوم 0.9→0.1، لون السماء رمادي→أزرق. لا تحميل، لا تبديل كائنات.
- **سينمائي ومُنمّق** (Stylized cinematic) أكثر من واقعي — ألوان مدروسة، إضاءة دراماتيكية، حركة كاميرا هادئة.
- **المعلومة أولاً:** المشهد خلفية. لا يسرق الانتباه من الرقم.

## 2. مكونات العالم (Layers)

```
┌──────────────────────────────────────────┐
│  Post-processing (Bloom, Vignette, Grade)│  ← طبقة نهائية
├──────────────────────────────────────────┤
│  Lightning flash (full-screen + bolt)    │
│  Precipitation (rain / snow) — Instanced │
│  Fog (height fog + distance fog)         │
│  Clouds (volumetric-look sprites/shader) │
│  Sun / Moon (+ god rays) / Stars         │
│  Sky dome (gradient shader)              │
│  Horizon + ground (reflective, subtle)   │
└──────────────────────────────────────────┘
        Camera: بطيئة، "تتنفس" (gentle drift + parallax مع الماوس)
```

## 3. حالة المشهد (SceneState)

كل حالة طقس تُترجم إلى هذا الكائن. المحرك يعمل lerp من القيم الحالية للقيم الهدف كل frame.

```ts
interface SceneState {
  // السماء
  skyTop: Color;          // لون أعلى السماء
  skyHorizon: Color;      // لون الأفق
  sunIntensity: number;   // 0..1
  sunElevation: number;   // -1..1 (من الوقت المحلي + شروق/غروب)
  moonIntensity: number;  // 0..1
  starsOpacity: number;   // 0..1

  // الغيوم
  cloudCoverage: number;  // 0..1
  cloudDarkness: number;  // 0 (أبيض) .. 1 (رمادي عاصف)
  cloudSpeed: number;     // مشتق من سرعة الرياح

  // الهطول
  rainIntensity: number;  // 0..1  (رذاذ ≈ 0.25، غزير ≈ 1)
  snowIntensity: number;  // 0..1
  precipAngle: number;    // ميلان (من سرعة + اتجاه الرياح)

  // الجو
  fogDensity: number;     // 0..1
  lightningFrequency: number; // ومضات/دقيقة (0 = لا يوجد)
  heatHaze: number;       // 0..1 تموج حراري عند الحر الشديد
  colorTemperature: number;   // -1 (بارد/أزرق) .. +1 (دافئ/برتقالي) من الحرارة

  // الإضاءة
  ambientIntensity: number;
  exposure: number;
}
```

**مصادر الأرقام:**
| المدخل من API | يؤثر على |
|---------------|----------|
| `weather_code` (WMO) | Preset الأساسي (الجدول بالأسفل) |
| `is_day` + الوقت المحلي + sunrise/sunset | sunElevation، ألوان السماء، القمر، النجوم |
| `wind_speed` + `wind_direction` | cloudSpeed، precipAngle، تمايل الجزيئات |
| `temperature` | colorTemperature، heatHaze (> 35°) |
| `cloud_cover` (%) | ضبط دقيق لـ cloudCoverage |
| `precipitation` (مم) | ضبط دقيق لـ rain/snow intensity |

## 4. ربط رموز WMO بالمشاهد

| رمز WMO | الوصف (عربي) | Preset | ملامح المشهد |
|---------|-------------|--------|--------------|
| 0 | صافٍ | `clear` | سماء نقية، شمس مع bloom وأشعة، أو قمر ونجوم ليلاً |
| 1 | صافٍ غالباً | `clear` | + غيوم خفيفة جداً |
| 2 | غائم جزئياً | `partly-cloudy` | غيوم بيضاء متفرقة تتحرك، الشمس تظهر وتختفي |
| 3 | غائم | `overcast` | سقف غيوم رمادي، إضاءة مسطحة ناعمة |
| 45, 48 | ضباب | `fog` | ضباب كثيف قرب الأرض، رؤية قصيرة، ألوان باهتة |
| 51, 53, 55 | رذاذ | `drizzle` | جزيئات مطر خفيفة وقصيرة، غيوم رمادية فاتحة |
| 56, 57 | رذاذ متجمد | `drizzle` | + لمسة زرقاء باردة |
| 61, 63, 65 | مطر (خفيف→غزير) | `rain` | خطوط مطر، رذاذ على الأرض، غيوم داكنة، أرض عاكسة مبللة |
| 66, 67 | مطر متجمد | `rain` | + تدرج بارد |
| 71, 73, 75 | ثلج | `snow` | ندف ثلج تتمايل ببطء، إضاءة بيضاء ناعمة، bloom خفيف |
| 77 | حبيبات ثلج | `snow` | جزيئات أصغر وأسرع |
| 80, 81, 82 | زخات مطر | `rain` | مطر متقطع على شكل موجات |
| 85, 86 | زخات ثلج | `snow` | ثلج بموجات |
| 95 | عاصفة رعدية | `storm` | غيوم شبه سوداء، مطر غزير مائل، **برق** + وميض يضيء الغيوم |
| 96, 99 | عاصفة مع برَد | `storm` | + جزيئات برَد بيضاء صغيرة سريعة |

**التعديلات الإضافية (Modifiers) فوق أي Preset:**
| الشرط | التعديل |
|-------|---------|
| ليل (`is_day = 0`) | سماء كحلية، قمر، نجوم (تختفي مع الغيوم)، إضاءة زرقاء باردة |
| شروق/غروب (± 45 دقيقة) | سماء برتقالية-وردية، شمس منخفضة، ظلال طويلة |
| رياح > 30 كم/س | غيوم سريعة، مطر مائل بقوة، جزيئات غبار/أوراق خفيفة |
| حرارة > 35° | تدرج دافئ + heat haze (تموج) + سماء باهتة |
| حرارة < 0° | تدرج أزرق بارد + لمعة صقيع |

## 5. سلوك الانتقال

- **المدة:** 1.5 ثانية افتراضياً (easeInOutCubic)، 2.5 ثانية للانتقالات الكبيرة (نهار ↔ ليل).
- **الترتيب الذكي:** عند الانتقال من مطر إلى صافٍ — المطر يتوقف أولاً، ثم الغيوم تنقشع، ثم الشمس تطلع. (staggering بسيط عبر تأخير كل طبقة).
- **الانقطاع:** إذا اختار المستخدم مدينة ثالثة أثناء انتقال، نبدأ من **القيم الحالية** نحو الهدف الجديد — بدون قفزة.
- **المشهد لا يتوقف أثناء التحميل** — يستمر بالحركة على الحالة السابقة.

## 6. ميزانية الأداء للمشهد

| العنصر | ديسكتوب (High) | موبايل (Medium) | ضعيف (Low) |
|--------|----------------|-----------------|------------|
| DPR | min(2, device) | 1.5 | 1 |
| جزيئات المطر | 15,000 | 5,000 | 1,500 |
| ندف الثلج | 6,000 | 2,500 | 800 |
| طبقات الغيوم | 3 | 2 | 1 |
| Post-processing | Bloom + Vignette + Grade | Vignette + Grade | لا شيء |
| God rays | نعم | لا | لا |
| Draw calls | < 40 | < 25 | < 15 |

- **قرار 2026-10-26:** الجودة **مثبّتة على Low** لكل الأجهزة، وأُلغي التبديل التلقائي. تغيير الجودة أثناء التصفح كان يعيد بناء الـ canvas ويسبب قفزة، والمستخدم ما لاحظ فرق بالشكل. الاستثناء الوحيد: المطر **16,000** والثلج **7,000** في كل المستويات، لأن حركتهم كلها على GPU وتكلفتهم قليلة. الجدول أعلاه مرجع فقط، وأرقام الجزيئات فيه قديمة. لوحة `?debug` ما زالت تسمح بالتبديل يدوياً للمقارنة.
- `prefers-reduced-motion`: جزيئات أقل وأبطأ، بدون حركة كاميرا، بدون برق وامض.
- التبويب مخفي (`document.hidden`): إيقاف حلقة الرسم.

## 7. طبقة الصوت

الصوت جزء من المشهد ويُقاد من نفس `SceneState` — نفس الأرقام اللي بتحرك المطر بتحرك صوت المطر.

| الصوت | يتحكم فيه | ملاحظات |
|-------|-----------|---------|
| مطر خفيف | `rainIntensity` 0 → 0.5 | loop |
| مطر غزير | `rainIntensity` 0.4 → 1 | loop، يتداخل مع الخفيف |
| رياح | `cloudSpeed` / سرعة الرياح | loop، الحجم والـ pitch يزيدوا مع السرعة |
| رعد | ومضة البرق | one-shot، تأخير 0.3–2s بعد الوميض (إحساس بالمسافة) |
| نهار هادئ (عصافير) | `clear` + نهار | loop، خفيف جداً |
| ليل هادئ (صراصير) | `clear` + ليل | loop، خفيف جداً |
| ثلج | `snowIntensity` | هدوء + رياح ناعمة مكتومة |

- حجم كل صوت = دالة من الأرقام → **crossfade تلقائي** مع انتقال المشهد بدون منطق إضافي.
- **شغّال افتراضياً**، يبدأ مع أول تفاعل للمستخدم (قيد autoplay في المتصفحات) بـ fade-in خلال ثانية.
- الملفات: loops قصيرة (10–20s) بصيغة **Opus/WebM** مع بديل **AAC** لـ Safari، ≤ 150KB للملف، إجمالي ≤ 1MB. تُحمّل **بعد** جاهزية المشهد.
- الحجم الكلي الافتراضي منخفض (≈ 40%) — جوّ، مش ضجة.

## 8. أدوات التطوير (Dev only)

- **لوحة تحكم (Leva)** مخفية تظهر بـ `?debug` في الرابط: اختيار أي Preset يدوياً، تحريك الوقت، الرياح، الحرارة — لنضبط كل مشهد بالعين قبل وجود بيانات حقيقية.
- **عداد FPS** (r3f-perf) في وضع debug.
- **Fixtures:** ملف بيانات وهمية لكل Preset (`clear-day`, `clear-night`, `rain`, `storm`, `snow`, `fog`, ...) لتجربة الانتقالات.
