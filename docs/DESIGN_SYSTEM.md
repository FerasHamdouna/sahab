# سحاب — نظام التصميم (Design System)

> مصدر الحقيقة للشكل. النموذج التفاعلي في [design/prototype.html](../design/prototype.html) مبني على هذه القيم بالضبط.
> الاتجاه مأخوذ من توصيات UI UX Pro Max لفئة "Weather App": **Glassmorphism + Aurora** فوق خلفية حيّة، Hero-centric.

---

## 1. الفكرة البصرية

- **السماء هي الخلفية والهوية.** الواجهة لا تملك لون خلفية خاص؛ لونها يأتي من المشهد.
- **الرقم الكبير يجلس مباشرة على السماء**، بدون بطاقة، مع ظل نص ناعم.
- **باقي المعلومات في بطاقات زجاجية** (blur + شفافية) تتكيف شفافيتها مع سطوع المشهد.
- **الشمس/القمر دائماً في الجهة المقابلة للنص** (inline-end) حتى لا يتصادما.
- **عمود الأيام السبعة ملتصق بالأسفل** على الديسكتوب، فتبقى السماء فوقه مكشوفة.

---

## 2. الألوان (Tokens)

الواجهة بنمط واحد داكن الحبر (نص فاتح فوق زجاج داكن) لأن المشهد نفسه يتغير بين الفاتح والداكن.

| Token | القيمة | الاستخدام |
|-------|--------|-----------|
| `--ink` | `#F5F8FD` | النص الأساسي |
| `--ink-2` | `rgba(240,245,252,.74)` | نص ثانوي |
| `--ink-3` | `rgba(240,245,252,.52)` | عناوين البطاقات، تسميات |
| `--glass` | `rgba(12,18,34, var(--glass-a))` | خلفية البطاقات |
| `--glass-a` | `0.20 → 0.44` | **ديناميكي**: يزيد مع سطوع المشهد (ثلج/صحو نهاري) لضمان تباين ≥ 4.5:1 |
| `--line` | `rgba(255,255,255,.14)` | حدود البطاقات |
| `--sun` | `#FFC873` | التمييز: الساعة الحالية، "مدينتي"، focus ring |
| `--rain` | `#8FD3FF` | احتمال الهطول |
| `--danger` | `#FF9C9C` | الأخطاء |

**سُلّم ألوان الحرارة** (أشرطة النطاق ونقاط المنحنى):

| °C | ≤ -10 | 5 | 15 | 25 | 35 | ≥ 45 |
|----|-------|---|----|----|----|------|
| اللون | `#6EB6FF` | `#7FD4F0` | `#9BE7C4` | `#FFD36B` | `#FF9A5B` | `#FF6B5B` |

**ألوان السماء لكل مشهد** موجودة في جدول `PAL` داخل النموذج، وهي نفس القيم اللي رح تنتقل لـ `presets.ts` في الفرونت إند.

## 3. الخطوط

| الدور | الخط | لماذا |
|-------|------|-------|
| Display (اسم المدينة، العلامة) | **Alexandria** 500–600 | هندسي عصري، يدعم العربي واللاتيني بنفس الروح |
| UI + الأرقام | **Readex Pro** 200–600 (variable) | مصمم للعربي واللاتيني معاً، وأوزانه الخفيفة (200) تعطي رقم حرارة أنيق وكبير |

- **الأرقام لاتينية (0–9)** في الواجهتين، وتُعزل باتجاه LTR (`unicode-bidi: isolate`) حتى لا تنقلب إشارة السالب في RTL (`-4°` وليس `4-°`).
- `font-variant-numeric: tabular-nums` لكل الأرقام المتراصفة.

| المستوى | الحجم | الوزن |
|---------|-------|-------|
| رقم الحرارة | `clamp(88px, 16cqi, 168px)` | 200 |
| اسم المدينة | 28px (موبايل 24) | 600 |
| الحالة | 22px | 400 |
| رقم في بطاقة | 28px | 300 |
| نص | 16px | 400 |
| تسمية/عنوان بطاقة | 13px | 500 |

---

## 4. المسافات والأشكال

- مقياس المسافات: `4 · 8 · 12 · 16 · 20 · 24 · 32 · 48`
- الفجوة بين البطاقات: 20px ديسكتوب / 12px موبايل
- زوايا: بطاقة **24px** · زر/حقل **14px** · شارة **999px**
- البطاقة: `backdrop-filter: blur(22px) saturate(150%)` + حد 1px + لمعة داخلية علوية خفيفة
- أهداف اللمس ≥ **44×44px** (الأزرار 48px)

---

## 5. الحركة

| النوع | المدة | المنحنى |
|-------|-------|---------|
| Hover / ضغط | 150–200ms | `cubic-bezier(.2,.7,.2,1)` |
| فتح قائمة الاقتراحات | 180ms | نفسه |
| عدّاد الحرارة | 650ms | ease-out cubic |
| سهم الرياح | 1s | ease-out |
| شفافية الزجاج | 1.2s | ease |
| **انتقال المشهد** | ≈1.5s (damping) | exponential |

`prefers-reduced-motion`: جزيئات أقل وأبطأ، بدون shimmer، بدون وميض برق قوي.

### ديسكتوب (≥ 900px عرض الحاوية)
```
┌──────────────────────────────────────────────────────────────┐
│ سحاب   [🔍 ابحث عن مدينة…                ]   📍 🔊 EN °C|°F │
├──────────────────────────────────────────────────────────────┤
│ عمّان ★                                         ☀ (الشمس)   │
│ الأردن · 14:32                                               │
│ 24°                                                          │
│ ⛅ غائم جزئياً                                ┌────────────┐ │
│ الإحساس 25° العليا 27° الدنيا 16°            │ 7 أيام     │ │
│ ┌─ الرياح ─────┐ ┌─ الرطوبة ────┐            │ اليوم ━━━  │ │
│ └──────────────┘ └──────────────┘            │ غداً  ━━━  │ │
│ ┌─ الـ 24 ساعة القادمة ──────────────────┐   │ ...        │ │
│ └────────────────────────────────────────┘   └────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

### موبايل (< 720px)
الترتيب: العلامة + الأزرار ← البحث بعرض كامل ← الرقم الكبير ← الرياح/الرطوبة جنباً لجنب ← 24 ساعة (تمرير أفقي) ← 7 أيام.

## 7. المكونات

| المكون | الحالات |
|--------|---------|
| حقل البحث | فارغ · تركيز (آخر عمليات بحث) · نتائج · لا نتائج · تنقل بالكيبورد |
| زر "موقعي" 📍 | عادي · جاري التحديد (دوران) · مرفوض |
| زر "مدينتي" ★ | غير مختارة · مختارة (نجمة ممتلئة) |
| زر الصوت | شغّال · بانتظار أول نقرة (نقطة) · مكتوم |
| بطاقة الترحيب | أول زيارة فقط |
| تنبيه | جاري التحديد · رفض الموقع · خطأ شبكة + إعادة المحاولة |
| Skeleton | يغطي النصوص والبطاقات، **والمشهد يستمر بالحركة** |

---

## 8. الأيقونات

خط رفيع (stroke 1.7) بأسلوب **Lucide**، SVG فقط، **لا emoji**. أيقونة لكل حالة طقس × (نهار/ليل) للصافي والغائم جزئياً.

---

## 9. قائمة الفحص قبل التسليم

- [ ] تباين ≥ 4.5:1 فوق أفتح مشهد (ثلج نهاراً) وأغمق مشهد (عاصفة ليلاً)
- [ ] كل الأزرار لها `aria-label`، والـ focus ظاهر
- [ ] RTL و LTR بدون كسر، والأرقام السالبة سليمة
- [ ] 375 · 768 · 1024 · 1440px بدون تمرير أفقي
- [ ] `prefers-reduced-motion` محترم
